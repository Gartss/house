# 基础功能增量检查（2026-09-09）

## 实现

- 小区档案由用户明确创建或选择，关联作为房源资料保存，不按名字自动合并。
- 独立成交价截图在房源详情导入，核对金额、单位、类型及统计时间后追加。共用同一档案的房源同步读取；对比表展示最后录入记录及其时间口径。
- 小区成交历史不可通过普通保存移除或改写；重复同图同值记录拦截。原图由现有身份隔离接口读取。
- 户型图上传后读取房间/面积标注，实际面积直接显示计入房间的合计；修改房间面积或计入选项时实时重算，保存房源后重开沿用明细。
- 阳台默认未勾选，用户可勾选计入；合计不覆盖建筑面积，建筑面积缺失不显示得房率。
- 支持选择识别区域并放大重新OCR；若遗漏，可补充明细。来源截图保留。
- 对比新增实际面积、得房率和小区成交价；缺失用空缺标记。
- 详情页位置支持“区域·板块”及 OCR 后的“区域：板块”，例如“闵行：梅陇”写入“闵行区 / 梅陇”。
- 详情截图只出现“户型”或“房型”时也会启动户型区域放大识别；识别结果直接填入实际面积，修改房间明细时实时更新。
- 截图字段改为按 OCR 文本语义匹配，不要求字段位于固定坐标；楼层段单独出现“低楼层 / 中楼层 / 高楼层”也会写入楼层字段。
- 截图未识别到报价日期时默认填写导入当天；房间面积明细默认展开，不再设置单独确认按钮。
- 房源列表不提供左滑编辑；点击房源名称进入详情编辑，避免横向查看表格时误触。
- 已保存的详情和报价可直接返回列表；只有仍有未保存字段时才提示放弃修改。

## 已知边界

- 实际户型截图OCR：整图无法稳定识别微小的房间面积，裁剪放大后能识别部分，仍需核对厨房/卫生间等漏项。
- 实际小区行情样例OCR的价格和标签错行，数字也存在误读；该图不会自动猜填成交金额。独立、清晰的成交价标签数字可按规则提取，复杂截图保留原图手填核对。
