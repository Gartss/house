# 基础功能增量检查（2026-09-09）

## 实现

- 小区档案由用户明确创建或选择，关联作为房源资料保存，不按名字自动合并。
- 独立成交价截图在房源详情导入，核对金额、单位、类型及统计时间后追加。共用同一档案的房源同步读取；对比表展示最后录入记录及其时间口径。
- 小区成交历史不可通过普通保存移除或改写；重复同图同值记录拦截。原图由现有身份隔离接口读取。
- 户型图上传后读取明确的房间/面积标注，编辑房间明细及计入选项；未确认完整时不显示总计。确认后保存至房源，重开沿用保存数据。
- 阳台默认未勾选，用户可勾选计入；确认前必须核对所有房间和计入方式。合计不覆盖建筑面积，建筑面积缺失不显示得房率。
- 支持选择识别区域并放大重新OCR；若遗漏，可补充明细。来源截图保留。
- 对比新增实际面积、得房率和小区成交价；缺失用空缺标记。

## 检查

- `property-extras.test.cjs`：房间提取排除建筑面积及尺寸；含阳台42.6㎡/84.95%，不含37.7㎡/75.17%；未确认或无有效房间不产生合计；分母缺失不产生比例；成交价/挂牌价隔离、单位转换；旧数据兼容；小区历史保护与来源关联校验。
- 原批量核对、OCR分条、价格涨跌和删除保护回归通过。
- 未改动或清空用户现有房源数据。

## 已知边界

- 实际户型截图OCR：整图无法稳定识别微小的房间面积，裁剪放大后能识别部分，仍需核对厨房/卫生间等漏项。
- 实际小区行情样例OCR的价格和标签错行，数字也存在误读；该图不会自动猜填成交金额。独立、清晰的成交价标签数字可按规则提取，复杂截图保留原图手填核对。
