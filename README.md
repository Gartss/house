# House · 看房对比与价格记录

项目根目录：`/Users/ppppp/Desktop/House/`。

## 项目目标

为个人看房提供干净的房源表格和价格走势图。通过房源截图提取信息，用户核对后保存，识别错误可以手动修改。

当前版本只做买房，以二手房收藏列表和房源详情截图为录入场景；暂不做租房。

运行载体：手机端网页，需在外出时通过移动网络访问。支持手机相册选择截图，按手机屏幕设计录入、核对和比较流程。当前已部署到用户指定的阿里云 ECS，数据库与图片保存在该 ECS 的持久化目录中。

## 已确认需求

- 对比不同小区、楼栋、楼层、户型和装修的房源价格。
- 手机直接以表格展示房源，一套一行、同类信息同列，支持编辑、排序和筛选。
- 待核对记录集中在可编辑表格内，勾选后批量保存；新增与相册导入置于底部悬浮区，备份收进更多菜单。
- 截图导入后提取字段；缺失信息留空，不猜测。
- 同一房源保留多次价格记录，用于走势图。
- 保留原始截图，方便核对。
- 手机优先，并支持外出访问；开发方案需包含私人访问保护、线上持久化保存与备份。
- 收藏列表截图支持批量提取多套待核对房源；同一套房的多张详情截图用于补全资料。
- 已提供截图中，图 1 为二手房收藏列表，图 3、4 为同一套房的详情；图 2 为租房列表，不纳入当前版本。

### 手机对比与删除（2026-09-08 更新）

已按确认方案改为按主题切换的窄表格，以及固定基准房源的双房源对比页。手机待核对按字段分组竖向填写。详情和列表支持单套/批量删除，待核对支持删除误识别记录；历史报价集中在同一面板中添加，单条记录可直接删除。原图文件不随房源删除。具体规则见需求文档最后一节。

对比页最新调整：每套房源固定一列、每个指标一行，选多少套就显示多少列，超宽时左右滑动；固定指标列及房源表头，不换行排列房源，也不使用上一套/下一套切换。价格走势包含全部所选房源。

经用户授权，已将生成的开发测试报价写入本地现有房源历史，移除示例切换入口。原有报价保留；生成记录的来源与编号保存在 work/generated-quote-provenance.json，后续用户要求时统一清理。

房源勾选框常驻；列表顶部“对比”按钮在选择不足两套时禁用，选择两套及以上可进入对比。选中任意房源后显示删除所选及清空选择。

价格变化：列表及对比页总价、当前单价旁显示相对上一条有效报价的变化，红色↑为上涨、绿色↓为下降，差值小字显示；持平显示灰色“−”，涨跌差值不带单位，只有一条报价不显示。当前单价优先按最新总价/面积计算，截图单价仍保留在资料中；没有面积时不推算单价变化。

已增强其他App关注列表的截图提取，支持面积/朝向/地址组合行及千位单价格式。已导入草稿可在“来源截图”下重新提取，核对后再保存。
